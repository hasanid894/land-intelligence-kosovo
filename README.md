# Land Intelligence Kosovo

An Expo and React Native prototype for exploring investment criteria and synthetic land-parcel examples.

## Run on Android with Expo Go

1. Install Node.js and the latest Expo Go app on your Android phone.
2. From the project folder, install dependencies:

   ```sh
   npm install
   ```

3. Start Expo using a tunnel:

   ```sh
   npm run start:tunnel
   ```

4. Scan the QR code shown in the terminal with Expo Go. Keep the terminal running while you use the app.

The tunnel command uses Expo's ngrok provider so an Expo account is not required.

The parcel examples and suitability scores are demonstration data only and are not verified assessments.
